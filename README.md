# Airline Passenger Satisfaction Prediction

## Project Overview
This project focuses on predicting airline passenger satisfaction using Machine Learning techniques.

## Objective
To analyse passenger and flight-related information and predict whether a passenger is satisfied or dissatisfied.

## Dataset
- Total records: 103,904
- Target variable: Satisfaction
- Problem type: Binary Classification

## Technologies Used
- Python
- Pandas
- NumPy
- Machine Learning
- Jupyter Notebook

## Project Description
- Explored airline passenger data.
- Analysed passenger and flight-related features.
- Worked with data preprocessing.
- Applied binary classification concepts to predict passenger satisfaction.
